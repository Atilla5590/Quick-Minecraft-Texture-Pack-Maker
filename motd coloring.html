🎨 MOTD Coloring Guide

You can color your Minecraft server MOTD using either the section sign (§) or the ampersand (&) followed by a code. These codes change the color or style of the text.

Color Codes

CodeColorExample
§0 / &0BlackBlack Text
§1 / &1Dark BlueDark Blue Text
§2 / &2Dark GreenDark Green Text
§3 / &3Dark AquaDark Aqua Text
§4 / &4Dark RedDark Red Text
§5 / &5Dark PurpleDark Purple Text
§6 / &6GoldGold Text
§7 / &7GrayGray Text
§8 / &8Dark GrayDark Gray Text
§9 / &9BlueBlue Text
§a / &aGreenGreen Text
§b / &bAquaAqua Text
§c / &cRedRed Text
§d / &dLight PurpleLight Purple Text
§e / &eYellowYellow Text
§f / &fWhiteWhite Text

Formatting Codes

CodeEffect
§l / &lBold
§o / &oItalic
§n / &nUnderline
§m / &mStrikethrough
§r / &rReset formatting

Use these codes in your MOTD or pack.mcmeta description to add flair and style. For example:

§6Welcome §bto §aQuickTexturePackMaker!
